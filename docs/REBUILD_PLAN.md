## 2. หลักการออกแบบ (แก้จุดเจ็บโดยตรง)

1. **Next Action First** — ทุกหน้าจอเปิดมาเจอ "สิ่งที่ต้องทำตอนนี้" ก่อนกราฟเสมอ กราฟอยู่ชั้นล่าง/หน้าลึก
2. **Zero-typing logging** — ลำดับความง่าย: Auto (Health Connect/แจ้งเตือนธนาคาร) → 1 แตะยืนยัน → 1 รูป → พิมพ์/พูดภาษาธรรมชาติ → ฟอร์ม (ทางสุดท้าย)
3. **App comes to you** — ไม่ต้องจำเปิดแอป: notification มีปุ่ม action (✓ ทำแล้ว / เลื่อน 15 นาที / บันทึก) ทำจบได้โดยไม่เปิดแอป + Home-screen widget
4. **Strict but smart** — เตือนซ้ำเฉพาะสิ่งสำคัญที่ยังไม่ทำ, เงียบเมื่อทำแล้ว, ไม่ spam
5. **น้อยแต่มาก** — 4 แท็บ + ปุ่มกลาง ไม่มีเมนูซ่อนลึกเกิน 2 ชั้น
6. **ทุกตัวเลขต้องมี "แล้วไง"** — เช่น "โปรตีนขาด 62g → ไข่ต้ม 3 ฟอง + อกไก่ใน meal prep กล่อง 2"
7. **ทุกอย่างยืดหยุ่น ไม่มีอะไรตายตัว** — ผู้ใช้เพิ่ม ลด แก้ไข ลบ ย้าย แทรก ได้ทุกอย่าง:
   - **ไม่มีค่าฝังในโค้ด**: ตาราง routine, โปรแกรมเวท, ท่า, checklist ยา/ผิว, หมวดเงิน, บิล, หนี้, การเตือน, เป้าโภชนาการ — ทุกอย่างเป็นข้อมูลที่แก้ได้ในแอป (แอปเดิมฝังตารางไว้ในโค้ด)
   - **"แค่วันนี้" หรือ "ทุกครั้งต่อจากนี้"**: แก้อะไรก็ตาม แอปถามว่าเปลี่ยนเฉพาะครั้งนี้หรือเปลี่ยนแม่แบบ (แบบปฏิทินที่ถามว่าเปลี่ยนนัดเดียวหรือทั้งชุด)
   - **ลากเพื่อย้าย/แทรก** ในไทม์ไลน์ รายการท่า checklist; ปัดเพื่อลบหรือเลื่อน
   - **ย้อนกลับได้ทุกอย่าง** (แถบ "เลิกทำ" 5 วินาที แทนกล่องยืนยัน) + ลบแบบกู้คืนได้ 30 วัน
   - **AI เสนอ ไม่ใช่บังคับ**: เป้าที่ AI คำนวณ ผู้ใช้ทับเองได้เสมอ และ AI ต้องเคารพค่าที่ผู้ใช้ตั้ง
   - **สั่งผ่านแชทได้**: "สลับวันพุธกับศุกร์", "เพิ่มเซ็ต RDL", "ลบเตือนครีมกันแดด" — โค้ชแก้ข้อมูลให้ทันที
   - **ไม่มีวันไหนพัง**: ถ้าข้าม ย้าย หรือทำไม่ครบ แอปจัดแผนที่เหลือใหม่ ไม่ลงโทษ (แต่โค้ชยังทวงตามโหมดเข้ม)

**Model routing (คุมงบ 100–300 ฿):**
- `claude-haiku-4-5` — parse แจ้งเตือนธนาคาร, จัดหมวด, แปลงข้อความ → log, สลิป
- `claude-sonnet-5-5` — วิเคราะห์รูปอาหาร, แชทโค้ช, weekly check-in
- Prompt caching สำหรับ system prompt + profile → ลดค่าใช้จ่ายหลายเท่า
- Rule-based ก่อน AI เสมอ (regex แจ้งเตือนธนาคารที่รู้ format) → AI เฉพาะกรณีไม่ match

**ระบบเตือน 2 ชั้น:**
- *Local* (แม่น ไม่ต้องใช้เน็ต): ยา, skincare, มื้ออาหาร, เวท, rest timer, บิล
- *Push จาก server* (ฉลาด): สรุปเช้า/ค่ำ, "โปรตีนยังขาด", "ใช้เงินเกิน pace", weekly check-in
- *Escalation (โหมดเข้ม)*: ไม่กด ✓ ภายใน 20 นาที → เตือนซ้ำ (ข้อความแรงขึ้น) สูงสุด 3 ครั้ง → บันทึกเป็น "พลาด" ให้โค้ชพูดถึงตอนค่ำ

## 5. ฟีเจอร์ตามบทบาท

### 5.1 เทรนเนอร์สุขภาพ (Phase 1–2)

**โภชนาการ — สร้างรอบ meal prep**
- **Recipe/Batch cook**: ใส่วัตถุดิบดิบ (กรัม) ครั้งเดียว → ระบบคำนวณมาโครต่อกล่อง → กินแต่ละกล่อง = 1 แตะ
- **Meal prep planner**: บอกเป้าสัปดาห์ → แนะนำปริมาณวัตถุดิบ + shopping list (ต่อยอด Meal Prep Calculator เดิม)
- **รูปอาหาร (Cal AI-style)**: สำหรับมื้อนอกบ้าน → Sonnet ประเมิน → แก้ portion ด้วย slider
- **Adaptive TDEE (MacroFactor-style)**: คำนวณ TDEE จริงจาก trend น้ำหนัก + การกิน → ปรับเป้าแคลอรี่ทุกสัปดาห์อัตโนมัติ
- เป้า recomp: deficit ~300–400 kcal, โปรตีน ~2.0 g/kg, carb cycling ตามวันเวท/บาส/พัก
- "Remaining macros → แนะนำมื้อจาก meal prep ที่มีอยู่"

**การฝึก — โปรแกรมจากอุปกรณ์จริง**
- **เวลาซ้อม: 08:15–09:20 ก่อนเริ่มงาน** (ดูตารางวันในหัวข้อ 5.1.1)
- ตารางร่าง (เน้นท่า compound หนัก + ความทนทานแบบ hybrid · ดัมเบลล้วน):
  - จ. **ช่วงบน A (ดัน/ดึงหนัก)**: DB bench press, lat pulldown, DB overhead press, DB row วางอก + **บาส (เย็น)**
  - อ. **ฟื้นตัว + ยืดเหยียด** 30 นาที (ข้อเท้า, สะโพก, หลังส่วนอก) + คาร์ดิโอโซน 2 30 นาที
  - พ. **ช่วงล่าง A (เน้นสควอต)**: DB front squat / goblet squat หนัก, Bulgarian split squat, DB RDL, leg extension ลงช้า, น่องยืน
  - พฤ. **ช่วงบน B (ปริมาณ)**: incline DB press, lat pulldown จับแคบ, DB row ขาเดียว, lateral raise, แขน
  - ศ. **ช่วงล่าง B (เน้นสะโพก) + hybrid**: DB RDL หนัก, reverse lunge, step-up, farmer carry, แกนกลางลำตัว + interval บนลู่
  - ส. คาร์ดิโอโซน 2 ยาว 40–60 นาที (ไม่บังคับ)
  - อา. พัก + เช็กอินประจำสัปดาห์
- **เสริมเอ็นและข้อเท้า** (ใช้เวลา 8–10 นาที แทรกในวันซ้อม):
  - เอ็นลูกสะบ้า: leg extension หรือ wall sit แบบเกร็งค้าง 45 วิ × 4
  - เอ็นน่อง: เขย่งลงช้า 3 วิ ขาเดียว 3×12
  - ข้อเท้าที่เคยพลิก: ยืนขาเดียวทรงตัว + เอียงข้อเท้าต้านยางยืด
- **ดัมเบลล้วนจะเบาเกินเร็ว** (โดยเฉพาะขา) → ระบบเพิ่มความยากด้วยวิธีอื่นอัตโนมัติ: ขาเดียว, ลงช้า 3–4 วิ, 1.5 ครั้ง, หยุดค้างล่าง, ลดเวลาพัก — ไม่ได้มีแค่ "เพิ่มน้ำหนัก"
- คาร์ดิโอ: เริ่มจากเดินลู่ชันสลับวิ่งเหยาะ แล้วเพิ่มช่วงวิ่งทีละสัปดาห์ (เพิ่มระยะไม่เกิน 10% ต่อสัปดาห์ เพื่อถนอมเอ็นน่อง)
- **Logger (Hevy-style)**: pre-fill น้ำหนัก/reps ครั้งก่อน, ปุ่ม ✓ ต่อเซ็ต, rest timer เด้ง notification, แนะนำ +2kg/+1 rep อัตโนมัติ (double progression)
- **Mobility day**: guided video/รูป + timer ทีละท่า
- Recovery score จาก sleep + resting HR (Health Connect) → ถ้าต่ำ แนะนำลด volume

ตัวอย่างวันซ้อม (ประมาณ 2,050 kcal · โปรตีน 170 g · คาร์บ 200 g · ไขมัน 55 g):

| มื้อ | เมนู (meal prep) | kcal | P | C | F |
|---|---|---|---|---|---|
| ก่อนซ้อม | กล้วย + เวย์ | 225 | 25 | 30 | 2 |
| เช้า | ไข่ 3 ฟอง + ข้าวโอ๊ต 50 g + ผลไม้ | 460 | 25 | 49 | 18 |
| กลางวัน | อกไก่ 150 g + ข้าว 180 g + ผัก 200 g | 570 | 53 | 60 | 10 |

| เย็น | หมูสันใน/ปลา 150 g + มันหวาน 200 g + ผัก | 500 | 46 | 50 | 13 |
| เติม | น้ำมันมะกอก/อะโวคาโดเพิ่มตามสะดวก | ~75 | 0 | 0 | 8 |

วันพัก:
- ตัดของว่างก่อนซ้อม แล้วย้ายเวย์ไปกินตอนบ่าย
- ลดข้าวเหลือ 120 g และมันหวานเหลือ 120 g → ได้ประมาณ 1,850 kcal

หลักประจำ:
- **โปรตีน**: แบ่ง 4–5 มื้อ มื้อละ 30–45 g
- **ผัก**: 400 g+/วัน · ไฟเบอร์ 30 g+
- **น้ำ**: ~3.3 ลิตร/วัน · วันซ้อมหรือวันเล่นบาสเพิ่มอีก 0.5–1 ลิตร
- **ครีเอทีน**: 5 g/วัน (ไม่ต้องโหลด)
- **ไขมัน**: ใช้น้ำมันตวงช้อนเสมอ ไม่กะด้วยตา เพราะเป็นจุดที่แคลอรี่หลุดบ่อยที่สุด
- **Meal prep**: ทำสัปดาห์ละ 2 รอบ (อาทิตย์ + พุธ) แต่ละรอบเก็บได้ 3–4 วัน · โปรตีนสลับ 3 อย่าง (ไก่ / หมูสันใน / ปลา) กันเบื่อ

ปรับแผนทุกอาทิตย์:
- ดูจากแนวโน้มน้ำหนักเฉลี่ย 7 วัน
- ลดเร็วกว่า 1 kg/สัปดาห์ → เพิ่ม 100–150 kcal
- ลดช้ากว่า 0.3 kg/สัปดาห์ติดกัน 2 สัปดาห์ → ลด 100–150 kcal

**ยา & ผิว** — checklist เช้า/ค่ำ (Ketoconazole/Sellon สลับวัน, Retacnyl/Benzac, Finasteride) ตั้งค่าได้ + nag

### 5.2 ผู้จัดการการเงิน (Phase 3)
- **Auto-capture**: ดักแจ้งเตือน K PLUS/SCB/KTB/บัตรเครดิต → regex/Haiku แยก จำนวน/ร้าน/บัญชี → เข้า **Inbox** → ปัดยืนยัน (จำหมวดจากร้านเดิมให้อัตโนมัติ)
- **Share slip** จากแอปธนาคาร → แอปอ่านเอง
- **Safe-to-spend วันนี้** = (เงินเข้าที่คาด − บิล − ยอดจ่ายหนี้ตามแผน − ออมฉุกเฉิน) ÷ วันที่เหลือ → ตัวเลขใหญ่ตัวเดียว
- **Debt payoff planner**: ใส่หนี้ (ยอด, ดอกเบี้ย, ขั้นต่ำ) → จำลองหลายแบบเทียบกัน (โปะก้อนดอกสูงก่อน / ก้อนเล็กก่อน / ไม่โปะ) → วันปลดหนี้, ดอกเบี้ยที่ประหยัด, กราฟนับถอยหลัง · ผู้ใช้เป็นคนเลือกแผนเอง
- **บัตรเครดิต**: เตือนวันตัดรอบ/วันครบกำหนด 5 วัน + 1 วันก่อน, เตือนถ้ายอดใช้เกินแผน
- **รอบเงินเดือน**: วันเงินเข้า → แอปแบ่งเงินให้เห็นทันที (คงที่ / หนี้ / สำรอง / ใช้ได้) · รายได้จากขายของบันทึกอัตโนมัติจากแจ้งเตือนเงินเข้า
- **Gamification ที่มีความหมาย**: วันที่ทำครบ → "โอนโปะหนี้ X บาท" แทน coins → travel fund

### 5.3 เลขา (Phase 4) — สำหรับพนักงานที่ทำงานที่บ้าน
- **สรุปตอนตื่น (~09:30)**: วันนี้มีอะไร, top 3 งาน, เวท/มื้อ, บิลใกล้ถึง, safe-to-spend
- **Auto time-blocking (Motion-style)**: anchors คงที่ (เวท, มื้อ, บาส, mobility) + งานที่มี estimate → จัดลงช่องว่างให้, ถ้าเลื่อนอะไร → จัดใหม่อัตโนมัติ
- **Deep work blocks + Pomodoro** พร้อมเตือนลุกยืน/ดื่มน้ำ (WFH นั่งนาน)
- **Quick capture inbox**: พิมพ์/พูดอะไรก็ได้ → AI แยกเป็น task / reminder / expense / food / note
- **ปิดวันก่อนนอน (~01:00)**: สรุปวัน, สิ่งที่พลาด, วางพรุ่งนี้ 1 นาที
- Google Calendar sync (2-way) — ทำท้าย phase

### 5.4 ที่ปรึกษา / โค้ช (Phase 5 แต่วางโครงตั้งแต่ Phase 0)
- แชทที่มี **tool use**: อ่านข้อมูลทุกส่วน + เขียนได้ (log อาหาร, สร้างเตือน, ย้าย block, เพิ่มรายจ่าย)
- **Coach memory**: จำ fact สำคัญ (ชอบ/ไม่ชอบ, อาการบาดเจ็บ, เป้า) แยกจากประวัติแชท
- **Weekly check-in (อาทิตย์)**: น้ำหนัก trend, adherence, volume, การเงิน, หนี้ → เสนอปรับแผน → กดยอมรับ
- Proactive cards บนหน้าวันนี้ (สูงสุด 3 ใบ เรียงตามความสำคัญ)
- Persona "เข้ม" ตั้งค่าได้ (เข้ม/สมดุล/อ่อนโยน)

## 6. Data Model (Firestore, single user)

```
users/{uid}
  profile        { name, sex, birth, heightCm, goal, tone, wakeTime, sleepTime, ... }
  targets/{weekId}  { kcal, protein, carb, fat, tdeeEstimate }
  days/{yyyy-mm-dd} { checklist{}, rings{}, summary, missed[] }
  foodLogs/{id}     { date, meal, items[], source: photo|recipe|text, kcal, p, c, f }
  recipes/{id}      { name, ingredients[], servings, perServing{} }
  workouts/{id}     { date, programDayId, exercises[{name, sets[{kg,reps,done}]}] }
  program           { days[], progressionRule }
  health/{date}     { steps, sleepMin, sleepScore, rhr, weightKg, bodyFat, source }
  transactions/{id} { ts, amount, merchant, category, account, status: pending|confirmed, raw }
  debts/{id}        { name, balance, apr, minPay, dueDay }
  bills/{id}        { name, amount, dueDay, account }
  income/{id}       { source: salary|resale|other, amount, date }
  tasks/{id}        { title, project, estimateMin, due, scheduledAt, status }
  reminders/{id}    { kind, time, rrule, escalation, linkedRef }
  coachMemory/{id}  { fact, source, updatedAt }
  chats/{id}        { messages[] }
```

**กติกาข้อมูลเพื่อความยืดหยุ่น (ใช้กับทุก collection):**
- ทุกรายการมี `order` (เรียง/แทรกได้), `deletedAt` (ลบแบบกู้คืนได้), `updatedAt`
- แยก **แม่แบบ** (`templates/*`: routine, โปรแกรมเวท, checklist, บิลประจำ) ออกจาก **รายการจริงรายวัน** (`days/*`, `workouts/*`)
- วันจริงเก็บเฉพาะส่วนที่ต่างจากแม่แบบ (`overrides`) → แก้ "แค่วันนี้" ไม่กระทบแม่แบบ
- ค่าที่ผู้ใช้ตั้งเอง มี `source: user|ai` → AI ห้ามเขียนทับค่า `user`

## 10. ความเสี่ยง / สิ่งที่ต้องทดสอบก่อน

- Zepp → Health Connect: ต้องเช็กว่า sleep/HR sync จริงบนเครื่องคุณ (บางรุ่นส่งแค่ steps/workout) → **spike ทดสอบใน Phase 0**
