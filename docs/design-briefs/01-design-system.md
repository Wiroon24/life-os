# โจทย์ Claude Design #1 — ระบบดีไซน์ (Design System) ของแอป "Iam"

## แอปนี้คืออะไร
แอปส่วนตัวบน Android (ใช้คนเดียว) ที่เป็น **เลขา + เทรนเนอร์สุขภาพ + ผู้จัดการการเงิน + ที่ปรึกษา AI** ในแอปเดียว
หน้าที่หลักคือบอกว่า "ตอนนี้ต้องทำอะไร" ไม่ใช่แค่โชว์ข้อมูล ผู้ใช้เป็นผู้ชายไทย อายุ 30 ปี ทำงานสาย IT ที่บ้าน
เป้าหมายตอนนี้คือลดไขมันพร้อมเพิ่มกล้าม และปลดหนี้

## บุคลิกของดีไซน์
- **สวย สนุก น่าใช้ สะอาด ใช้ง่าย น้อยแต่มาก**
- สนุกแบบ Duolingo / Finch / Gentler Streak: มีจังหวะฉลองเล็กๆ เมื่อทำสำเร็จ แต่ไม่รก ไม่เด็ก
- สะอาดแบบ Things 3 / Copilot Money: ช่องว่างเยอะ ลำดับชัด ตัวเลขสำคัญตัวใหญ่ตัวเดียว
- โค้ชพูดตรงและเข้ม แต่หน้าตาต้องเป็นมิตร ไม่กดดัน

**โหมดสว่างเท่านั้น** ทำตามแนวทางด้านล่าง ถ้าเห็นว่าค่าไหนปรับแล้วดีขึ้นได้ (เช่น ความสดของสี คอนทราสต์) ปรับได้ แต่ต้องคงแนวเดิม

## แนวทางที่กำหนดแล้ว: "สดใส สะอาด มีจังหวะ" (Fresh Light)
- **พื้นหลัง**: ขาวนวลอุ่น `#F6F5F1` · การ์ดเป็นสีขาว `#FFFFFF` · ไม่ใช้เส้นขอบ ให้แยกชั้นด้วยสีพื้นต่างกันและเงาบางมาก
- **ตัวอักษร**: `#17181C` · ตัวรอง `#77756D` · ปุ่มรองใช้สีดำ
- **สีหลัก** `#FF5A36` (ส้มคอรัล): ใช้เฉพาะการ์ด "ทำตอนนี้" ปุ่ม ⊕ และปุ่มสำคัญที่สุดของหน้า ไม่ใช้พร่ำเพรื่อ
- **สีตามบทบาท**: กิน `#FF9F1C` · ซ้อม `#22B455` · ฟื้นตัวและนอน `#7C5CFF` · เงิน `#2F7BFF` (แต่ละสีมีเฉดอ่อนไว้ใช้เป็นพื้นรางวงแหวนและชิป)
- **ฟอนต์**: Anuphan ทั้งแอป · ตัวเลขใหญ่ใช้น้ำหนัก 600
- **รูปทรง**: การ์ดโค้ง 20–22 px · ปุ่มทรงแคปซูล · แถบเมนูล่างเป็นแคปซูลลอย มีปุ่ม ⊕ วงกลมสีหลักอยู่ตรงกลาง
- **ความสนุก**: มาจากสีบทบาทที่สดใส วงแหวนที่เติมแบบเด้งๆ และแอนิเมชันฉลองเล็กๆ ตอนทำสำเร็จ ไม่ใช้มาสคอต ไม่ใช้ภาพประกอบเยอะ
- **หน้า "วันนี้"** เรียงจากบนลงล่าง:
  1. คำทักทายพร้อมวันที่
  2. การ์ด "ทำตอนนี้" สีหลัก (ใหญ่สุดในหน้า)
  3. แถววงแหวน 4 วง (กิน / ซ้อม / ฟื้นตัว / ใช้ได้)
  4. การ์ดคำแนะนำจากโค้ช
  5. ไทม์ไลน์ "ต่อจากนี้"


- หน้าจอ Android กว้าง 360–412 px รองรับ safe area และแถบนำทางของระบบ
- ภาษาไทยเป็นหลัก ต้องมีฟอนต์ไทยที่อ่านง่ายและมีน้ำหนักครบ (เสนอได้ เช่น IBM Plex Sans Thai, Noto Sans Thai, LINE Seed Sans TH, Anuphan) จับคู่กับฟอนต์ตัวเลขที่สวยสำหรับตัวเลขใหญ่
- ทำทุกอย่างเป็นตัวแปร (สี ขนาด ระยะ มุมโค้ง เงา จังหวะ animation) เพื่อนำไปเขียนโค้ดตรงๆ
- ปุ่มและพื้นที่แตะต้องไม่ต่ำกว่า 48 px และคอนทราสต์ผ่าน WCAG AA

## สีตามบทบาท (ให้แยกกันชัดแต่อยู่ร่วมกันได้)
| บทบาท | ใช้กับ |
|---|---|
| หลักของแอป | ปุ่มหลัก, ปุ่ม ⊕ ตรงกลาง |
| กิน / โภชนาการ | วงแหวนแคลอรี่, โปรตีน, คาร์บ, ไขมัน (แยก 3 สีย่อย) |
| ซ้อม / ร่างกาย | เวท, คาร์ดิโอ, การฟื้นตัว |
| เงิน | ใช้ได้วันนี้, หนี้, รายรับและรายจ่าย |
| สถานะ | สำเร็จ / เตือน / พลาด / ข้อมูล |

## ชิ้นส่วนที่ต้องออกแบบ (พร้อมสถานะ: ปกติ / กด / ปิดใช้งาน / โหลด / ว่าง / ผิดพลาด / สำเร็จ)
1. **แถบนำทางด้านล่าง**: 4 แท็บ (วันนี้ · ร่างกาย · เงิน · โค้ช) กับปุ่ม ⊕ ตรงกลางที่เด่นที่สุด
2. **การ์ด "ทำตอนนี้"** (Next Action): การ์ดใหญ่ใบบนสุดของหน้าแรก มีปุ่ม ✓ ทำแล้ว / เลื่อน / ข้าม รองรับการปัด
3. **วงแหวนความคืบหน้า**: ทั้งแบบเดี่ยวและแบบชุด 4 วง (กิน / ซ้อม / ฟื้นตัว / งบ)
4. **ตัวเลขใหญ่** (Hero number) พร้อมคำอธิบายสั้น ตัวอย่าง: "ใช้ได้วันนี้ 612 ฿"
5. **รายการในไทม์ไลน์**: บล็อกเวลาที่มีที่จับสำหรับลากย้าย และปัดซ้ายหรือขวาเพื่อลบหรือเลื่อน
6. **Checklist item**: แบบที่ติ๊กแล้วมีแอนิเมชันฉลองเล็กๆ
7. **แถวบันทึกเซ็ตเวท**: น้ำหนัก × ครั้ง ปุ่ม ✓ และค่าจากครั้งก่อนแสดงจางๆ
8. **แผ่นเลื่อนขึ้นจากด้านล่าง** (Bottom sheet) ใช้กับการแก้ไขทุกอย่าง
9. **ตัวเลือก "แค่วันนี้ / ทุกครั้งต่อจากนี้"** ใช้ทุกครั้งที่แก้สิ่งที่เป็นแม่แบบ
10. **แถบเลิกทำ** (Undo snackbar 5 วินาที) ใช้แทนกล่องยืนยันการลบ
11. **โหมดแก้ไขรายการ**: เพิ่ม ลบ ลากเรียง แทรกระหว่างรายการ (ปุ่ม "+" แทรกระหว่างแถว)
12. **การ์ดคำแนะนำจากโค้ช**: มีปุ่มทำตามได้ทันที
13. **ฟองแชท**: ผู้ใช้ / โค้ช / การ์ดผลลัพธ์ที่ AI สร้าง (เช่น "บันทึกอาหารแล้ว 540 kcal" พร้อมปุ่มแก้)
14. **ชิป / แท็ก / ตัวเลือกช่วง** (วัน สัปดาห์ เดือน)
15. **กราฟเล็ก** (sparkline) และกราฟเส้นแนวโน้มน้ำหนัก
16. **หน้าว่างและหน้าฉลอง**: ภาพประกอบหรือไอคอนสไตล์เดียวกันทั้งแอป
17. **รูปแบบแจ้งเตือน Android**: ปกติ / มีปุ่มทำแล้วและเลื่อน / เตือนซ้ำแบบเข้ม
18. **วิดเจ็ตหน้าจอหลัก**: ขนาด 2×2 และ 4×2

## หลักที่ต้องเห็นได้จากดีไซน์
- **ทุกอย่างแก้ได้**: ผู้ใช้ต้องรู้สึกว่าทุกอย่างเพิ่ม ลด ย้าย หรือลบได้ แต่ปุ่มแก้ไขต้องไม่รกหน้าจอ (แสดงเมื่อกดค้าง หรือเมื่อเข้าโหมดแก้ไข)
- **ทุกตัวเลขมี "แล้วไง"** ตัวอย่าง: "โปรตีนขาด 62 g → ไข่ต้ม 3 ฟอง + อกไก่กล่อง 2"
- **บันทึกให้น้อยแตะที่สุด**: ทางเลือกแรกคือ 1 แตะ หรือถ่ายรูป 1 รูป

## ข้อมูลตัวอย่างที่ใช้ในการ์ดทดลอง (ภาษาไทย)
- ตอนนี้: "ช่วงล่าง A · 6 ท่า · ~55 นาที" | "ทาครีม Retacnyl ก่อนนอน"
- กิน: 1,240 / 2,100 kcal · โปรตีน 98 / 160 g
- ร่างกาย: 96.0 → 95.2 kg (แนวโน้ม −0.6 kg/สัปดาห์)
- เงิน: ใช้ได้วันนี้ 612 ฿ · เงินเดือนเข้าอีก 9 วัน · หนี้รถเหลือ 56 งวด
- โค้ช: "เมื่อคืนนอน 5 ชม. วันนี้ลดน้ำหนักเวทลง 10% แล้วเข้านอนก่อน 00:30 นะ"

## สิ่งที่ต้องส่งกลับมา
1. ระบบดีไซน์ตามแนวทาง Fresh Light (โหมดสว่าง)
2. ตารางตัวแปร (tokens) ของสี ฟอนต์ ระยะ มุมโค้ง เงา และ animation
3. หน้ารวมชิ้นส่วนทั้ง 18 รายการ พร้อมทุกสถานะ
4. หน้าตัวอย่าง 1 หน้า ("วันนี้" แบบคร่าวๆ) เพื่อดูว่าชิ้นส่วนอยู่ร่วมกันแล้วเป็นอย่างไร
