# โจทย์ Claude Design #2–#8 — หน้าจอทั้งหมดของแอป Iam

วิธีใช้: ส่งให้ Claude Design **ทีละโจทย์** ในโปรเจกต์เดิม (ที่ทำระบบดีไซน์และหน้า "วันนี้" ไว้แล้ว)
คัดลอกตั้งแต่ "─── เริ่มคัดลอก ───" จนถึง "─── จบ ───" ของแต่ละโจทย์

**ทุกโจทย์ใช้กติกาเดียวกัน (อยู่ในตัวโจทย์แล้ว):**
- ใช้ระบบดีไซน์ Fresh Light เดิม (สี ฟอนต์ ชิ้นส่วน)
- หน้าจอ Android กว้าง 360–412 px
- โหมดสว่างเท่านั้น
- ทุกหน้าต้องมีสถานะ: ว่าง / กำลังโหลด / ผิดพลาด / สำเร็จ
- ทุกอย่างในแอปแก้ไขได้ (เพิ่ม ลบ ลากเรียง แทรก, ถาม "แค่วันนี้ / ทุกครั้งต่อจากนี้", เลิกทำได้)

## #2 หน้า "วันนี้" ฉบับเต็ม

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light ที่ทำไว้ในโปรเจกต์นี้ ออกแบบแท็บ "วันนี้" ให้ครบทุกหน้าและทุกสถานะ (Android 360–412 px, โหมดสว่าง)

หน้าที่ต้องมี:
1. **หน้าวันนี้ 4 ช่วงเวลา** (การ์ด "ทำตอนนี้" เปลี่ยนตามเวลา):
   - เช้า: ก่อนซ้อม → "กล้วย + เวย์" แล้วต่อด้วย "ช่วงล่าง A"
   - ระหว่างวัน: "ลุกเดิน 5 นาที" และ "มื้อกลางวัน กล่อง meal prep 2"
   - เย็น: "มื้อเย็น" และ "บาส 19:00" (เฉพาะวันจันทร์)
   - ก่อนนอน: "ทา Retacnyl" และ "ปิดวัน"
2. **ทำครบทุกอย่างแล้ว**: แอนิเมชันฉลอง + สรุปวันสั้นๆ
3. **วันที่ทำพลาดหลายอย่าง**: โค้ชพูดตรงแต่ไม่ซ้ำเติม + ปุ่ม "จัดแผนที่เหลือใหม่"
4. **ไทม์ไลน์เต็มวัน** (กดจาก "ต่อจากนี้"):
   - บล็อกเวลาแยกสีตามบทบาท
   - บล็อกที่ผ่านไปแล้วแสดง ✓ / ข้าม / พลาด
   - มีเส้นบอกเวลาปัจจุบัน
5. **โหมดแก้ไขไทม์ไลน์**:
   - ลากย้ายบล็อก ยืดหรือหดเวลาได้
   - ปุ่ม "+" สำหรับแทรกระหว่างบล็อก
   - ปัดเพื่อลบ
   - เมื่อแก้ ให้เลือก "แค่วันนี้ / ทุกครั้งต่อจากนี้"
6. **Checklist ยาและผิว** (เช้า / ก่อนนอน):
   - ติ๊กได้ทีละข้อ
   - รายการสลับวันได้ (Ketoconazole/Sellon วันเว้นวัน)
   - แก้รายการได้
7. **สรุปตอนตื่น** (เปิดจากแจ้งเตือนตอนเช้า):
   - เมื่อคืนนอนกี่ชั่วโมง และคะแนนฟื้นตัว
   - วันนี้ซ้อมอะไร
   - 3 เรื่องสำคัญ
   - ใช้เงินได้วันนี้เท่าไหร่
8. **ปิดวัน** (ก่อนนอน):
   - วันนี้ทำได้กี่ %
   - สิ่งที่พลาด
   - ตั้งพรุ่งนี้ใน 1 นาที
   - ปุ่ม "นอนแล้ว"

ข้อมูลตัวอย่าง:
- นอน 6 ชม. 40 นาที · ฟื้นตัว 78
- กิน 1,240 / 2,100 kcal · โปรตีน 98 / 160 g
- ใช้ได้วันนี้ 612 ฿
- น้ำหนักแนวโน้ม 95.2 kg

ไม่เอาเกิน 2 ชั้นของการกดเข้าไป

## #3 ปุ่ม ⊕ บันทึก (กล้อง / พูด / พิมพ์)

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบ flow ของปุ่ม ⊕ ตรงกลางแถบเมนู ซึ่งเป็นทางบันทึกทุกอย่างในแอป (Android, โหมดสว่าง)

1. **แผ่นเลื่อนขึ้นเมื่อกด ⊕**:
   - ตัวเลือกใหญ่ 3 อย่าง: ถ่ายรูป / พูด / พิมพ์
   - แถวทางลัด 1 แตะ: กินกล่อง meal prep, ดื่มน้ำ +500 ml, ชั่งน้ำหนัก, บันทึกรายจ่าย
   - รายการที่บันทึกบ่อยล่าสุด
2. **หน้ากล้อง**: ถ่ายอะไรก็ได้ แล้ว AI แยกเองว่าเป็น อาหาร / สลิปโอนเงิน / ใบเสร็จ / ผล InBody / หน้าจอนาฬิกา
3. **ผลลัพธ์ "อาหาร"**:
   - รูป + รายการอาหารที่ AI เห็น
   - slider ปรับปริมาณ แล้วแคลอรี่และมาโครเปลี่ยนตาม
   - เลือกมื้อ
   - ปุ่ม "บันทึก"
4. **ผลลัพธ์ "สลิปหรือใบเสร็จ"**:
   - จำนวนเงิน ร้าน และหมวดที่ AI เดา
   - แก้หมวดได้ 1 แตะ
5. **ผลลัพธ์ "InBody"**:
   - ตารางเทียบกับครั้งก่อน: น้ำหนัก, กล้ามเนื้อ, ไขมัน %, ไขมันช่องท้อง
   - ใช้ลูกศรขึ้นลงพร้อมสีบอกว่าดีหรือแย่
6. **ผลลัพธ์ "หลายอย่างในข้อความเดียว"**:
   - ตัวอย่างพิมพ์ว่า "กินข้าวมันไก่ 60 บาท"
   - แอปแยกเป็น 2 การ์ด คือ อาหาร + รายจ่าย
   - ยืนยันทีเดียว
7. **หน้าพูด**: คลื่นเสียง + ข้อความที่ถอดได้แบบสด
8. **AI ไม่แน่ใจ**: ถามกลับ 1 คำถามพร้อมตัวเลือก อย่าให้พิมพ์

หลักสำคัญ: จากกด ⊕ จนบันทึกเสร็จต้องไม่เกิน 3 แตะในกรณีปกติ

## #4 แท็บ "ร่างกาย" — ซ้อม

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบส่วน "ซ้อม" ในแท็บร่างกาย (Android, โหมดสว่าง) แท็บร่างกายมีตัวสลับด้านบน 3 ส่วน คือ ซ้อม / กิน / แนวโน้ม

ผู้ใช้: ผู้ชาย 96 kg เป้าหมายแข็งแรงแบบ hybrid อุปกรณ์มีดัมเบล ม้านั่ง ลู่วิ่ง leg extension และ lat pulldown

หน้าที่ต้องมี:
1. **ภาพรวมสัปดาห์**: 7 วัน
   - จ. ช่วงบน A + บาส
   - อ. ฟื้นตัว + ยืดเหยียด
   - พ. ช่วงล่าง A
   - พฤ. ช่วงบน B
   - ศ. ช่วงล่าง B + hybrid
   - ส. คาร์ดิโอ
   - อา. พัก
   - วันที่ทำแล้วมี ✓ และลากสลับวันได้
2. **ก่อนเริ่มซ้อม**:
   - รายการท่า เวลาโดยประมาณ
   - วอร์มข้อเท้าและเข่า 8 นาที
   - ปุ่ม "เริ่ม"
3. **หน้าบันทึกเซ็ต** (หน้าสำคัญที่สุด):
   - ชื่อท่าตัวใหญ่
   - แต่ละเซ็ตเป็นแถว น้ำหนัก × ครั้ง
   - ค่าครั้งก่อนแสดงจางๆ
   - ปุ่ม ✓ ใหญ่ กดด้วยนิ้วโป้งได้ขณะถือดัมเบล
   - ป้ายคำแนะนำ เช่น "+1 ครั้ง จากครั้งก่อน" หรือ "ลองลงช้า 3 วิ"
4. **ตัวจับเวลาพัก**:
   - วงนับถอยหลังเต็มจอแบบย่อได้
   - ปุ่ม +30 วิ / ข้าม
5. **สลับท่า / เพิ่มท่า / ลบท่า / ลากเรียงท่า** ระหว่างซ้อม พร้อมถาม "แค่วันนี้ / ทุกครั้ง"
6. **ซ้อมเสร็จ**:
   - เวลารวม ปริมาณรวม (kg)
   - สถิติใหม่ (PR) แบบฉลอง
   - ให้คะแนนความเหนื่อย 1–10
7. **ยืดเหยียดและเสริมข้อต่อ** (โหมดเล่นตาม):
   - ท่าละการ์ด รูปหรือวิดีโอ + ตัวจับเวลา
   - ข้ามหรือย้อนได้
   - ตัวอย่างท่า: เขย่งลงช้าขาเดียว, wall sit ค้าง 45 วิ, ยืนขาเดียวทรงตัว
8. **แก้โปรแกรม**:
   - แก้วัน ท่า เซ็ต ครั้ง เวลาพัก
   - คลังท่า ค้นหาและกรองตามอุปกรณ์
9. **ประวัติท่า**: กราฟน้ำหนักและครั้งของท่า DB bench press ย้อนหลัง

แรงบันดาลใจ: Hevy (บันทึกเร็ว), Apple Fitness (ฉลอง), Bevel (สะอาด)

## #5 แท็บ "ร่างกาย" — กิน และ แนวโน้ม

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบส่วน "กิน" และ "แนวโน้ม" ในแท็บร่างกาย (Android, โหมดสว่าง)

**ส่วน "กิน"** — ผู้ใช้ทำ meal prep เองเป็นหลัก

1. **วันนี้**:
   - วงแหวนแคลอรี่ใหญ่ 1 วง + แถบโปรตีน / คาร์บ / ไขมัน
   - รายการมื้อตามเวลา
   - การ์ด "ยังขาดอีก" พร้อมคำแนะนำจากอาหารที่มีในตู้
   - ตัวอย่าง: ขาดโปรตีน 62 g → ไข่ต้ม 3 ฟอง + อกไก่กล่อง 2
2. **ตู้ meal prep**:
   - กล่องที่เหลือในตู้ (เช่น อกไก่ข้าวผัก ×3, หมูสันในมันหวาน ×2)
   - แตะกล่องเดียว = บันทึกว่ากินแล้ว
   - เตือนเมื่อกล่องใกล้หมดอายุ
3. **สร้างสูตรหรือทำ batch**:
   - ใส่วัตถุดิบดิบเป็นกรัม แบ่งเป็นกี่กล่อง
   - แอปคำนวณมาโครต่อกล่องให้
   - ตัวช่วยคำนวณย้อนกลับ: "อยากได้โปรตีน 45 g ต่อกล่อง ต้องใช้อกไก่เท่าไหร่"
4. **รายการซื้อของ** จากแผน meal prep สัปดาห์ ติ๊กได้
5. **น้ำ**: ตัวนับแบบแตะเพิ่ม 250 / 500 ml (เป้า 3.3 ลิตร)
6. **เป้าโภชนาการ**:
   - วันซ้อม 2,100 / วันพัก 1,850 kcal
   - แสดงว่า AI ตั้งให้ หรือผู้ใช้ตั้งเอง
   - แก้เองได้

**ส่วน "แนวโน้ม"**

7. **น้ำหนัก**:
   - จุดรายวันจางๆ + เส้นค่าเฉลี่ย 7 วันชัดๆ
   - เส้นเป้าหมายแบ่งเป็นด่าน (90 → 84 → 79 kg)
   - บอกวันที่คาดว่าจะถึงแต่ละด่าน
8. **InBody**: ไทม์ไลน์ผลแต่ละครั้ง เน้นกล้ามเนื้อ (ต้องไม่ลด) กับ % ไขมัน
9. **การนอนและการฟื้นตัว**: แท่งชั่วโมงนอนรายวัน + เส้นเวลาเข้านอน เทียบกับเป้า 00:15
10. **เช็กอินประจำสัปดาห์** (วันอาทิตย์):
    - สรุปสัปดาห์
    - ข้อเสนอปรับแผน เช่น "+100 kcal" หรือ "เพิ่มเซ็ตขา"
    - ปุ่ม ยอมรับ / แก้ / ไม่เอา

แรงบันดาลใจ: MacroFactor (แนวโน้มและเป้าที่ปรับเอง), Cronometer (ความละเอียด แต่ต้องดูไม่รก)

## #6 แท็บ "เงิน"

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบแท็บ "เงิน" (Android, โหมดสว่าง)

ผู้ใช้:
- เงินเดือนสุทธิ 33,600 บาท เข้าวันที่ 28 → รอบงบนับจากวันที่ 28
- ค่าใช้จ่ายคงที่ 14,500: บ้าน 8,900 · รถ 4,383 · มือถือ 500 · Claude ~700
- มีรายได้เสริมจากขายของมือสอง (ยอดไม่แน่นอน)
- จ่ายบัตรเต็มทุกเดือน
- หนี้: รถเหลือ 56 งวด, กยศ. ~22,000 (หักจากเงินเดือน), บ้าน 2.17 ล้าน (ดอกเบี้ยคงที่ 2.3% ถึงปี 2029)

หน้าที่ต้องมี:
1. **หน้าหลัก**:
   - ตัวเลขใหญ่ตัวเดียว "ใช้ได้วันนี้ 612 ฿"
   - ใต้ตัวเลข: เหลืออีก 9 วันถึงเงินเดือน · ใช้ไปแล้ว 62% ของงบ
   - แถบเทียบกับจังหวะที่ควรใช้
2. **กล่องรอยืนยัน**:
   - รายการที่ดึงมาจากแจ้งเตือนธนาคาร (กสิกร, KTC) เอง
   - ปัดขวา = ยืนยัน, ปัดซ้าย = ไม่ใช่ / ลบ
   - แตะ = เปลี่ยนหมวด
   - ยืนยันทั้งหมดได้ในครั้งเดียว
3. **รายการทั้งหมด**:
   - จัดกลุ่มตามวัน กรองตามหมวด
   - ตัวอย่าง: ร้านอาหาร 60 ฿, Grab 145 ฿, 7-Eleven 89 ฿
   - รายรับจากขายของแสดงสีต่างกัน
4. **วันเงินเดือนเข้า**:
   - หน้าจอพิเศษ แบ่งเงินให้เห็น: ค่าคงที่ / หนี้ / เงินสำรอง / ใช้ได้ต่อวัน
   - ผู้ใช้ลากปรับสัดส่วนได้
5. **หนี้**:
   - การ์ดหนี้แต่ละก้อน พร้อมแถบความคืบหน้าและวันที่คาดว่าจะหมด
   - หน้าจำลอง: ใส่เงินโปะเพิ่มต่อเดือน → เทียบหลายแบบ (ก้อนดอกสูงก่อน / ก้อนเล็กก่อน / ไม่โปะ) → ดอกเบี้ยที่ประหยัด และวันปลดหนี้
   - ผู้ใช้เลือกแผนเอง
6. **บิลและวันสำคัญ**:
   - รายการบิลประจำพร้อมวันครบกำหนด
   - วันตัดรอบบัตร KTC
   - การ์ดเตือน "ดอกเบี้ยบ้านคงที่หมดใน X เดือน"
7. **แก้หมวด งบ และบิล**: เพิ่ม ลบ ลากเรียง ได้ทุกอย่าง

แรงบันดาลใจ: Copilot Money (สะอาด ตัวเลขชัด), YNAB (ทุกบาทมีหน้าที่), Undebt.it (นับถอยหลังปลดหนี้)

## #7 แท็บ "โค้ช"

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบแท็บ "โค้ช" ซึ่งเป็นแชทกับ AI ที่รู้ข้อมูลทุกอย่างของผู้ใช้ และสั่งงานได้ (Android, โหมดสว่าง)

บุคลิกโค้ช: เข้ม พูดตรง ตามทวง แต่ใส่ใจ ไม่ประชด

หน้าที่ต้องมี:
1. **หน้าแชท**:
   - ด้านบนมีชิปคำถามด่วน: "วันนี้กินอะไรดี", "เลื่อนเวทได้ไหม", "สรุปสัปดาห์"
   - ช่องพิมพ์ด้านล่างมีปุ่มไมค์และกล้อง
2. **ฟองข้อความที่มีการ์ดผลลัพธ์**:
   - ตัวอย่าง: ผู้ใช้พิมพ์ "สลับวันพุธกับศุกร์"
   - โค้ชตอบพร้อมการ์ดแสดงตารางก่อนและหลัง และปุ่ม "เลิกทำ"
3. **การ์ดบันทึก**:
   - ตัวอย่าง: "บันทึกอาหารแล้ว 540 kcal · โปรตีน 42 g"
   - มีปุ่มแก้
4. **โค้ชทักก่อน** (เช่น ไม่ได้บันทึกอาหารตั้งแต่เที่ยง):
   - ข้อความเข้มแต่สุภาพ
   - ปุ่มตอบด่วน 2–3 ปุ่ม
5. **เช็กอินประจำสัปดาห์**:
   - แชทแบบมีขั้นตอน
   - ถามความรู้สึก 1–5 → สรุปตัวเลข → ข้อเสนอปรับแผน
   - ยอมรับทีละข้อได้
6. **"สิ่งที่โค้ชจำได้"**:
   - รายการเรื่องที่ AI จำ (เช่น "เคยพลิกข้อเท้า", "ไม่ชอบปลาทู")
   - แก้หรือลบได้
7. **ตั้งค่าบุคลิก**: เข้ม / สมดุล / อ่อนโยน พร้อมตัวอย่างข้อความของแต่ละแบบ

ฟองข้อความของโค้ชต้องแยกจากผู้ใช้ให้ชัด ไม่ต้องมีมาสคอต

## #8 เริ่มใช้งาน, ตั้งค่า, แจ้งเตือน, วิดเจ็ต

─── เริ่มคัดลอก ───
ใช้ระบบดีไซน์ Fresh Light เดิม ออกแบบส่วนที่เหลือของแอป (Android, โหมดสว่าง)

1. **เริ่มใช้งานครั้งแรก** (8–10 หน้าแบบคุยกัน ทีละคำถาม ตอบด้วยปุ่มเป็นหลัก):
   - ชื่อ → ข้อมูลร่างกาย (หรือถ่ายรูป InBody แทนการกรอก) → เป้าหมาย → ประวัติบาดเจ็บ → อุปกรณ์ที่มี → วันและเวลาซ้อม → เวลาตื่นและนอน → ยาและผิว → เงินเดือนกับวันเงินเข้า → หนี้ → บุคลิกโค้ช
   - หน้าสุดท้าย: "แผนของคุณพร้อมแล้ว" สรุปเป้าแคลอรี่ ตารางซ้อม และวันที่คาดว่าจะถึงด่านแรก
   - ขออนุญาตทีละอย่างพร้อมเหตุผล: แจ้งเตือน, Health Connect, อ่านแจ้งเตือนธนาคาร
2. **โปรไฟล์และตั้งค่า** (เข้าจาก avatar มุมบน):
   - แม่แบบทั้งหมดอยู่ในที่เดียว: ตารางวัน, โปรแกรมซ้อม, checklist, หมวดเงิน, บิล
   - การเชื่อมต่อ: Health Connect, แอปธนาคาร
   - ตั้งค่าแจ้งเตือน
   - ถังขยะ (กู้คืนได้ 30 วัน)
3. **ตั้งค่าแจ้งเตือน**:
   - แต่ละเรื่องเปิดปิดได้ ตั้งเวลาได้
   - ระดับการทวง: เตือนครั้งเดียว / ทวงซ้ำ 3 ครั้ง
   - ช่วงห้ามรบกวน
4. **หน้าตาแจ้งเตือน Android** (mockup บนหน้าจอล็อก):
   - "ถึงเวลาซ้อม ช่วงล่าง A" [เริ่ม] [เลื่อน 15 นาที]
   - "ทา Retacnyl ก่อนนอน" [ทำแล้ว]
   - ทวงรอบ 3: "ยังไม่ได้ทายาเลยนะ อีก 10 นาทีจะบันทึกว่าพลาด" [ทำแล้ว]
   - "มีรายการรอยืนยัน 3 รายการ" [เปิด]
   - "สรุปเช้า: นอน 6.7 ชม. · วันนี้ช่วงบน B · ใช้ได้ 612 ฿"
5. **วิดเจ็ตหน้าจอหลัก**:
   - 2×2: การ์ดทำตอนนี้ + ปุ่ม ✓
   - 4×2: วงแหวน 4 วง + ทำตอนนี้
   - 1×1: ปุ่ม ⊕ บันทึกด่วน
